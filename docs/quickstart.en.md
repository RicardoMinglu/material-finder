# Quick start

1. Verify SHA-256 and the test status of the Windows x64 EXE or Mac ARM64 DMG candidate.
2. Install and launch. Builds are unsigned; follow your OS's opening flow only after verifying the source.
3. Click “选择资料文件夹” to select one root. Subfolders are included. Native text becomes searchable before OCR finishes.
4. Enter a phrase or space-separated keywords. Every keyword must match. Filter by file type or subfolder.
5. Click a result to inspect highlights. “复制片段及出处” copies an excerpt and location; “打开原文件” opens the original.
6. “资料管理” shows progress, paginated files, failures, pause/resume and retry controls.

Switching roots replaces the index after confirmation and never deletes originals. Restore temporarily unavailable folders before refreshing. No Office, Python, external Tesseract or model API is required. Word uses paragraphs/embedded images instead of page layout. Handwriting, equations and poor scans are outside the clear-print OCR guarantee.
