# 1.1.0-rc.1 候选版

将“离线搜索资料并定位原文”的现有应用整理为独立 MIT 开源工程。

- 搜索、列表、预览元数据在查询子进程执行；主进程不执行同步 SQLite。
- 流式候选、有限堆与线性覆盖区间排序，保留既有 AND、高亮及分页语义。
- 文件管理分页、摘要状态事件、连续查询去旧结果。
- 复制片段及相对出处；更换资料库前确认；显示版本与存储占用。
- 安全清理失去引用的缓存，并修复同内容文件重新加入后的快照重建。
- 处理进程异常后提示，用户下一次操作恢复。
- 新增固定中文质量集、1 万页规模测试、原生安装包测试入口及双语文档。

数据库表结构与 1.0.1 一致；普通版、商店版各自保留原数据目录。升级不主动重建已完成 OCR。商店身份和签名不进入公开工程。

Windows 为交叉构建候选包，原生安装、升级、断网 OCR 和高缩放尚待验证。Mac 仍未签名、公证。详细测试条件与结果见 VERIFICATION.md。
