# 支持范围与限制

- 仅中文界面；文档提供英文版本。Windows x64、Mac ARM64；不声明 Linux、Intel Mac 或 Windows ARM 支持。
- 一次一个根文件夹；支持子文件夹。切换会替换索引。
- 文字关键词检索，不是语义搜索或 AI 问答。空格分词为 AND；短词可能命中大量内容。
- 首次 OCR 较慢；速度与图像、CPU 和页数相关。识别结果需要结合原文核对。
- 模糊、低对比、旋转、拉伸、复杂表格、公式和手写效果不保证。正常空白页可能没有识别文字。
- Word 无原版排版和可靠页码；旧 DOC 图片不识别。密码保护文档需要先解锁。
- 仅索引常规文件；不跟随符号链接，不纳入视频或不支持的格式。
- 索引和不可变内容快照需要额外磁盘空间，可能接近源资料体积加索引；管理页显示占用。
- 未签名、未公证；Windows 实机及高缩放验收必须与跨平台构建结果区分。
- 没有遥测、云识别或自动更新。公开基准为合成资料，不能推断所有真实资料的质量和速度。
