# 快速使用

1. 从 [GitHub 预发布页](https://github.com/RicardoMinglu/material-finder/releases/tag/v1.1.0-rc.1)选择 Windows x64 EXE 或 Mac ARM64 DMG，核对 SHA-256。
2. 安装并启动。未签名应用可能触发系统信任提示；确认文件来源后按系统提供的打开流程操作。
3. 选择一个资料文件夹。普通 PDF 文字通常先出现；扫描件和图片随后进行 OCR。
4. 输入文字或空格分隔关键词，例如“采购 审批”。左侧可按类型及子目录筛选。
5. 点击结果，查看高亮；复制片段及出处，或打开原文件。
6. 资料管理中可查看进度、分页浏览、筛选失败项、暂停和重试。

更换根文件夹将替换当前索引，不删除原文件。图片识别中搜不到的内容可能尚未完成；检查待识别数量和失败列表。文档暂时不可访问时先恢复目录访问，再刷新。

不需要 Office、Python、Tesseract 或在线模型。复杂公式、手写、模糊和明显变形图片不能保证识别。Word 使用段落和内嵌图片定位。

下载或安装遇到问题，请查看 [安装与常见问题](faq.md)。
